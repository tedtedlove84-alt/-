# ANDWITH Host OS — 앤드 테스트

앤드 숙소의 예약 달력, 정산·손익, 운영 추천을 검증하기 위한 **비공개 내부 운영도구 프로토타입**입니다. 외부 판매용 SaaS가 아닙니다.

ANDWITH Host OS는 현장 채팅이나 청소기사 작업과정을 통제하는 PMS가 아닙니다. 예약·담당자·수입을 한눈에 확인하고, 숙소별 리스팅의 노출·전환·수익을 개선하며, 공동호스트의 판단과 결과를 축적하는 의사결정 도구입니다. 현장 소통·사진·파손·비품·지연 처리는 카카오톡 단체방에서 진행합니다.

## 파일 4개의 역할

- `index.html`: 앱 화면과 문구
- `styles.css`: 색상·달력·모바일 화면 디자인
- `app.js`: 화면 전환, 달력 생성, iCal/CSV 읽기
- `README.md`: 실행법과 현재 범위 설명

네 파일은 각각 역할이 다르지만 사용자는 `index.html`만 열면 하나의 앱으로 보게 됩니다.

코딩 환경 없이 화면만 확인할 때는 CSS와 JavaScript가 모두 포함된 `andwith-demo.html` 한 파일을 내려받아 브라우저로 엽니다. 이 파일은 익명 샘플 전용이며 실제 운영자료를 저장하는 용도가 아닙니다.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 <http://localhost:4173>을 열면 됩니다. 실제 외부 링크로 접속하려면 이후 비공개 웹 서버에 배포해야 합니다.

## 이번 테스트에 포함된 것

- 앤드 오늘의 운영과 우선 판단 3개
- 2026년 8월 전체 예약 달력과 인원·청소 담당자 표시
- 판매 가능일 예약률, 예약박, 평균 숙박기간
- 6~7월 자료를 바탕으로 한 7월 손익 미리보기
- iCal 주소 저장 및 iCal 원문 분석
- CSV 파일/붙여넣기 거래행 분류
- 확인된 월간 성과와 운영 변경기록을 연결하는 인사이트 화면
- 일별 자료가 없으면 그래프를 생성하지 않고 `입력 대기`로 표시하는 데이터 원칙
- 누락 비용을 직접 추가하고 세전 예상 운영이익을 다시 계산하는 손익 화면
- 여러 숙소에 재사용할 수 있는 발견→전환→운영→이익 진단과 소유주 보고서 구조
- 상단 숙소 선택기에서 새 숙소를 등록하고 숙소별 표시색으로 전환하는 흐름
- 기본 완성도·검색 적합도·클릭 경쟁력·예약 전환을 나누는 리스팅 진단 화면
- `전체 숙소` 선택 시 1~31일을 가로로 펼쳐 숙소별 예약 막대를 동시에 보는 통합 달력
- 청소 담당자 배정·미정 경고·담당자 필터와 카카오톡용 일정 복사
- 숙소별 리스팅 기본정보·비교숙소·변경 전후·관찰기간 저장
- 공식 확인·데이터 기반 추정·운영 가설을 구분한 최대 3개 추천

## 데이터 수집 원칙

- iCal: 예약·차단 날짜 자동 확인
- Paid/Upcoming CSV: 예약자·금액·정산 확인
- 총인원: iCal에 없으므로 새 예약만 버튼으로 보완
- 청소: 달력에 담당자 이름과 비용만 기록하고 현장 소통은 카카오톡 사용
- Airbnb가 제공하지 않는 노출·문의·검색순위·알고리즘 점수는 임의 생성하지 않고 `자료 없음` 또는 `입력 대기`로 표시

현재 버전은 화면과 운영 흐름을 검증하는 브라우저 프로토타입입니다. CSV 금액을 영구 장부로 확정하거나 에어비앤비의 가격·메시지를 자동 변경하지 않습니다.

## 공개 미리보기 안전기준

공개 미리보기에는 익명 예약명과 예시 금액만 사용합니다. 실제 게스트 이름, 예약코드, 결제 참조번호, 정확한 주소, 계좌정보 및 토큰이 포함된 iCal 주소는 배포하지 않습니다. 주소를 아는 사람은 누구나 볼 수 있는 공개 데모와 실제 운영자료를 저장하는 비공개 앱을 분리합니다.
